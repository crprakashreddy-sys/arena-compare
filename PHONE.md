# See zappd live using only your phone

1. Install **Expo Go** from the App Store or Play Store.
2. In the terminal at the bottom of this screen, type `npm run phone` and press Enter.
   (If it says "ngrok" needs installing, type `y` and press Enter.)
3. Wait for a line like `Metro waiting on exp://abcd-anonymous-8081.exp.direct`.
4. Long-press that `exp://…` address and copy it.
5. Open Safari (iPhone) or Chrome (Android), paste it into the address bar and go.
   Your phone asks to open **Expo Go**: tap **Open**. zappd loads in about a minute.

Keep this browser tab open while you use the app; closing it stops the app.
